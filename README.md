## 📌 Project Overview

This project showcases the Exploratory Data Analysis (EDA) and data visualization pipeline performed on the **US Car Auction Dataset** as a dynamic web application.

### ✨ Key Features
- **Code & Visual Integration:** Walkthroughs explaining data processing steps alongside their corresponding charts.
- **Instant Access:** Cloud-deployed and fully accessible directly from any web browser with zero local setup.
